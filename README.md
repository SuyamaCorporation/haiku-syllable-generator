# Haiku 5-7-5 Syllable Composer
Write haiku poetry with real-time syllable counting and visual feedback for each of the three lines.
## Features
- Three-line editor with real-time syllable count per line (green=correct, yellow=too few, red=too many)
- Seasonal kigo (season word) suggestion panel with 20 words each for Spring, Summer, Autumn, Winter
- Save haikus to a local gallery with timestamps
- Copy haiku to clipboard and clear editor buttons
- Random classic haiku inspiration button featuring works by Bashō, Buson, and Issa
## Usage
Type in each line and watch the syllable counter update in real time. Click seasonal kigo words to insert them into the next incomplete line. Save finished haikus to your gallery.
